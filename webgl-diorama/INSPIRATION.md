# 引导素材

用户靠"挑"来创作。这份文件管两件事：怎么出题，以及没有灵感时从哪取材。

## 出题规矩

- **选项是画面，不是术语。** 描述写用户会看到、感到什么——"月光下桂花一片片旋转着落进水里"，而不是"粒子系统"。技术名词只进提示词。
- **从已知里长出来。** 主题一定，生灵、飘落物、彩蛋都从主题推导（中秋 → 玉兔、桂花雨、嫦娥奔月）。下面的素材库是缺灵感时的兜底。
- **拉开差距。** 同一题的选项落在不同方向（静 ↔ 闹、冷 ↔ 暖、写实 ↔ 童趣），每个选项都是一个不同的想法。
- **推荐项放第一个**，标"（推荐）"：与已选内容最搭、最出效果的那个。
- **只给做得出的。** 每个选项都能落到 IMPLEMENTATION.md 技法速查的某一行。人物只出现在体素、低多边形风格里；流体、布料、大群写实人物换成粒子与简化形体的近似。
- 每题 2–4 个选项；AskUserQuestion 会自动附上"其他"，想自己写的用户走那里。

## 方案卡题（用户什么都没给时）

一道单选题，3–4 张方案卡：label 是方案名（如「雪夜温泉」），description 一句话概括，preview 放完整的场景卡（格式见 SKILL.md），让用户直接"看见"成品。

组卡要求：
- 至少一张贴合当下时令或临近节日（看今天的日期，对照下方时令表）；
- 至少两种风格载体；
- 至少一张静谧、一张热闹。

**时段氛围**：月夜 · 静谧（清冷月光 + 暖色灯火）｜黄昏 · 温暖（金色斜阳、长影子）｜雨后清晨 · 清新（湿润反光、薄雾、光束）｜雪夜 · 温馨（落雪、窗里透出暖光）｜正午 · 明亮热闹（饱和色、清晰阴影）｜深夜 · 神秘（萤光、浓雾、冷色）

**生灵**（小主角 + 招牌小动作）
- 毛茸茸：兔子（转耳、嗅鼻子）、猫（舔爪、甩尾巴）、柯基（摇尾巴、歪头）、狐狸（竖耳、蜷成一团）、松鼠（捧着坚果啃）、刺猬（缩成球）、小猕猴（泡澡打盹）
- 带羽毛：猫头鹰（转头、眨眼）、麻雀（蹦两步、啄地）、鸭子（划水、抖羽毛）、企鹅（摇摇摆摆）
- 水里的：金鱼 / 锦鲤（绕着荷叶游）、热带鱼群（聚拢又散开）、小乌龟（伸脖子）、青蛙（鼓腮、跳上荷叶）
- 小不点：蜗牛（慢慢爬、留下水痕）、萤火虫（一明一灭）、蝴蝶（停在花上扇翅）、瓢虫（沿叶脉爬）
- 体素 / 低多边形：各司其职的小人（搬运、巡逻、指挥）、来回跑的小车

**飘落物**：花瓣（樱花、桂花、桃花）｜落叶（红枫、银杏）｜雪花｜雨丝｜萤火｜蒲公英绒毛｜气泡｜光尘｜烟花余烬

## 第二轮：玩法

| header | 问题 | 选项来源 |
|---|---|---|
| 双击 | 双击场景会发生什么？ | 双击表，套到本场景的物件和生灵上 |
| 彩蛋 | 按空格来一场什么大场面？ | 彩蛋表，与主题呼应，起个四字名（如"嫦娥奔月"） |
| 面板 | 右下角面板能调什么？（多选，挑 2–3 个） | 面板表 |

**双击**（动作 → 效果 → 生灵反应）
- 双击水面 → 一圈涟漪扩散，倒影被打散又复原 → 小主角转头看过去
- 双击地面 → 撒下一把鱼食 / 种子 → 鱼群或鸟儿聚过来吃
- 双击小主角 → 它跳一下 / 打个滚 / 抖抖毛 → 身边的飘落物被惊起
- 双击树或花 → 摇落一阵花瓣 → 小主角抬头看
- 双击灯 → 灯亮起或熄灭 → 萤火虫围过来

**彩蛋**（约 10 秒的大场面）：流星雨 / 金光划过夜空｜烟花绽放｜狂风卷起漫天落花落叶｜暴雨或大雪骤至｜萤火虫群从草丛升起｜极光铺满天空｜万灯齐亮｜时间快进，天色流转一轮

**面板**：飘落物密度｜灯光亮度｜时段切换（清晨 / 黄昏 / 夜晚）｜天气切换（晴 / 雨 / 雪）｜风力｜生灵活跃度
