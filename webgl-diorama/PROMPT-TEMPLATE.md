# 提示词模板

`{…}` 是槽，其余是固定句，原样保留。各段条目数照模板写。填好的完整样例是 EXAMPLES.md 提示词 1，它的实现在 `reference/mid-autumn-moon/`。

```
用 WebGL (Three.js r160 CDN) 创作一个{精细度与风格}的{主题}{载体}场景，输出为可直接在 Chrome 打开的单个 HTML 文件，不引用任何外部资源，全部几何体、材质、贴图（使用 Canvas/Shader 过程生成）代码生成，目标稳定 60FPS，杜绝物体穿模。

场景载体：整套{主题}微缩模型摆放在{桌面}上，桌面边角散落{3–4 件呼应主题的桌面小物}。

视觉视角：全屏近距离平视与微俯瞰视角，镜头聚焦于{视觉中心}。镜头支持平滑旋转与缩放，展现{值得凑近看的质感}。

场景主体布局：{一句话定调}，包含{主体物件}。

动态元件与生态：
1. {主角动态}（{English}）：{…}
2. {环境动态}：{…}
3. {生灵}：{…}

光影与{氛围名}：
1. {主光与冷暖对比}：{…}
2. {空气层次}：{…}

交互系统与沉浸模式：
1. 沉浸隐藏：按下键盘 H 键可无缝触发/退出“纯净沉浸模式”，自动平滑淡出隐藏所有 UI 控制面板、文本提示与按键引导，只留纯净的 3D 渲染画面；按下 F 键切换全屏。
2. 视角控制：鼠标左键拖拽平滑环视{场景}，滚轮缩放观察{微观细节}；闲置时相机自动缓速巡航。
3. {对象}互动：鼠标双击{对象}，{视觉效果}，{生灵的反应}。
4. 界面控制：右下角极简透明 UI 控制面板：调节{面板项}；按下空格键触发“{彩蛋名}”，{彩蛋画面}。

技术要求：
1. 批渲染优化：{数量多的物体}大量使用 InstancedMesh 批渲染以保障帧率；
2. 高级材质：使用 MeshPhysicalMaterial 呈现{材质质感}；
3. Shader 核心：自定义 Shader 实现{自定义着色效果}；
4. 碰撞与边界：所有{会动的东西}严格限制在{固体与边界}以内，杜绝穿模。
5. 视觉质感：{氛围词}，呈现{风格与美学}。
```

"场景载体"一段只在桌面沙盘里保留，其他载体删掉整段。

## 填槽

| 槽 | 填法 | 提示词 1 的填法 |
|---|---|---|
| 精细度与风格 | "高精细度、写实{情绪}风格" / "高精细度、体素风格" / "高精细度、低多边形童话风格" | 高精细度、写实浪漫风格 |
| 载体 | 微观角落 / 微缩沙盘 / 生态鱼缸 / 玻璃罩… | 微观角落 |
| 视觉中心 | 1–2 个最大的主体，带位置 | 静谧水面上的古朴木质水榭亭台与盛开的金桂树 |
| 值得凑近看的质感 | 2–3 处，写"什么光下的什么质感" | 清冷月光下的金桂高光、水波倒影与玉兔毛发质感 |
| 主体物件 | 5–7 个，从大到小，每个带一个材质或形态细节 | 横跨清澈水面的微型石拱桥、带翘角飞檐的古朴木质水榭…… |
| 主角动态 | 场景里最大、最吸睛的动态，括号里写技术名 | 满月与月晕（Volumetric Moon） |
| 环境动态 | 植物怎么摆 + 飘落物从哪来、落到哪、落下后怎样（水上漂 / 地上停） | 桂花雨与水波 |
| 生灵 | 小主角的 2–3 个招牌小动作 + 另一种更小的生物 | 玉兔的眨眼、转耳；荷叶间游动的金鱼 |
| 主光与冷暖对比 | 一冷一暖两种光源 | 清冷月光与灯笼暖辉 |
| 空气层次 | 雾、光束、光尘里挑 1–2 样 | 桂香薄雾 |
| 对象互动 | 第 2 步定下的因果链：动作 → 效果（带技术名）→ 生灵反应 | 双击水面 → 金色涟漪（Ripples Shader）打散月影 → 玉兔转头 |
| 面板项 | 2–3 项；枚举类写出档位，如"时段色温（清晨冷光/夕阳金黄/夜间月光）" | 落桂花瓣密度、灯笼亮度与月晕范围 |
| 彩蛋名 / 彩蛋画面 | 四字名；画面写清天上、空中、地面各发生什么 | 嫦娥奔月 / 金光粒子划过夜空，桂花雨加密，水面泛起金色波光 |
| 数量多的物体 | 所有成百上千的东西：叶、花瓣、草、石子、粒子、体素块 | 桂花花瓣、荷叶、桂花树叶与夜雾粒子 |
| 材质质感 | 2–3 种；有水加"水面高折射率（IOR 1.33）"，有玻璃加"超白玻璃（IOR 1.52）" | 白瓷釉面、木质清漆、玉兔毛发 SSS、水面 IOR 1.33 |
| 自定义着色效果 | 2–3 项，取自 IMPLEMENTATION.md 技法速查 | 月晕漫射、水面月影倒影、花瓣漂浮位移 |
| 会动的东西 / 固体与边界 | 列全所有会动的东西，边界写到具体的固体和水域 | 玉兔、金鱼、落花与水滴 / 庭院固体与池水边界网格 |
| 氛围词 / 风格与美学 | 两组氛围词；体素风格加"体素方块颗粒质感明显" | 温馨浪漫，诗意盎然 / 中秋月夜东方美学 |

技术名一律写成"中文（English）"，用技法速查"提示词写法"一列的说法，实现时才对得上号。
