# 范例提示词

四条已验证的场景提示词。1–3 为"微观角落"写实风格，4 为"桌面沙盘"体素风格。提示词 1 的完整实现见 `reference/mid-autumn-moon/`。

提示词1：
用 WebGL (Three.js r160 CDN) 创作一个高精细度、写实浪漫风格的中秋月夜与水榭桂花微观角落场景，输出为可直接在 Chrome 打开的单个 HTML 文件，不引用任何外部资源，全部几何体、材质、贴图（使用 Canvas/Shader 过程生成）代码生成，目标稳定 60FPS，杜绝物体穿模。

视觉视角：全屏近距离平视与微俯瞰视角，视角聚焦于静谧水面上的古朴木质水榭亭台与盛开的金桂树。镜头支持平滑旋转与缩放，展现清冷月光下的金桂高光、水波倒影与玉兔毛发质感。

场景主体布局：一个静谧祥和的中秋月夜角落，包含一座横跨清澈水面微型石拱桥、一座带翘角飞檐的古朴木质水榭、一株满树金黄且不断飘落花瓣的盛开桂花树、水面上一汪倒映着巨大满月的波光月影、几朵写实粉白荷花与荷叶，以及石桌上摆放的微型精致月饼与白瓷茶杯。

动态元件与生态：
1. 满月与月晕（Volumetric Moon）：夜空中有一轮巨型高精细度的写实满月，带有地表陨石坑纹理与向四周漫射的柔和金色月晕（Moon Halo Shader）；月光穿透薄云投射出清澈的丁达尔日光/月光束。
2. 桂花雨与水波：桂花树在夜风中轻微摇曳，金黄色的微型桂花花瓣不断从树上缓缓旋转飘落（粒子系统），落在水面上顺着涟漪漂浮；水面缓缓流动，完美倒映出巨型满月与水榭的写实倒影（Planar Reflection Shader）。
3. 动态玉兔与微观生态：水榭旁的白念珠石上有一只体态写实柔软的白毛玉兔，偶有眨眼、转动耳朵与停歇的微动作，毛发带有柔和的次表面散射高光（SSS）；池水中有极小型的写实金鱼在荷叶阴影间悠闲游动。

光影与中秋氛围：
1. 清冷月光与灯笼暖辉：场景由顶部的清冷金白色月光与水榭下挂着的几盏红纸灯笼暖光共同照亮，产生强烈的冷暖光影对比。
2. 桂香薄雾：水面上缭绕着一层薄薄的微光夜雾粒子，金桂花瓣在月光照射下发出微弱的金色高光。

交互系统与沉浸模式：
1. 沉浸隐藏（核心）：按下键盘 H 键可无缝触发/退出“纯净沉浸模式”，自动平滑淡出隐藏所有 UI 控制面板、文本提示与按键引导，只留纯净的 3D 渲染画面；按下 F 键切换全屏。
2. 视角控制：鼠标左键拖拽平滑环视场景，滚轮缩放观察玉兔毛发、月饼纹理与桂花花瓣细节；闲置时相机自动缓速巡航。
3. 水面互动：鼠标双击水面月亮倒影任意位置，激起一圈写实向外扩散的金色涟漪（Ripples Shader），将水中的月亮倒影打散而后又渐渐复原，附近的玉兔会好奇地转头看向水面。
4. 界面控制：右下角极简透明 UI 控制面板：调节落桂花瓣密度、灯笼亮度与月晕范围；按下空格键触发“嫦娥奔月/金波狂想”，夜空中划过绚丽的写实金光粒子，桂花雨密度提升，水面泛起强烈的金色波光。

技术要求：
1. 批渲染优化：成千上万片桂花花瓣、荷叶、桂花树叶与夜雾粒子大量使用 InstancedMesh 批渲染以保障帧率；
2. 高级材质：使用 MeshPhysicalMaterial 呈现白瓷茶杯的釉面高光、木质水榭的清漆感、玉兔毛发的次表面散射（SSS）与水面高折射率（IOR 1.33）；
3. Shader 核心：自定义 Shader 实现巨型月晕漫射、水面动态月影倒影与桂花花瓣漂浮位移；
4. 碰撞与边界：所有玉兔、金鱼、落花与水滴严格限制在庭院固体与池水边界网格以内，杜绝穿模。
5. 视觉质感：温馨浪漫，诗意盎然，光影层次丰富且极具节日氛围，呈现最高质感的中秋月夜东方美学。

提示词2：
用 WebGL (Three.js r160 CDN) 创作一个高精细度、写实风格的雨后日式禅意庭院微观角落场景，输出为可直接在 Chrome 打开的单个 HTML 文件，不引用任何外部资源，全部几何体、材质、贴图（使用 Canvas/Shader 过程生成）代码生成，目标稳定 60FPS，杜绝物体穿模。

视觉视角：全屏近距离平视与微俯瞰视角，相机聚焦于庭院角落的竹制惊鹿（添水）与古朴石灯笼。镜头支持平滑旋转与缩放，展现雨后湿润的岩石纹理与叶片水珠。

场景主体布局：一个精致的雨后庭院角落，包含不断积水与倾倒的竹制惊鹿（添水）、表面长满写实青苔的古朴石灯笼、铺满细碎湿润卵石的地面、几株枝叶繁茂的红枫树、竹篱笆墙以及一小片带波纹的静谧水洼。

动态元件与生态：
1. 添水与水流：竹筒（惊鹿）接满水后因重力缓缓倾倒，水流注入下方石钵，激起写实水花与扩散涟漪。
2. 动态植物与雨滴：细雨绵绵，雨滴粒子倾泻落于石灯笼与枫树叶片上，溅起微型水花；红枫叶片与竹枝在微风中产生自然平滑的摆动动画（顶点位移）。
3. 昆虫与落叶：石灯笼旁有一只极小型的写实蜗牛在湿润的岩石表面缓慢爬行，留下微弱的水痕；偶尔有几片体态写实的红枫叶从空中缓缓旋转飘落，浮在水洼表面随波纹漂浮。

光影与水汽系统：
1. 湿润材质（Wetness Shader）：地面卵石、石灯笼与树叶具备写实的“雨后湿润”高光与光泽度，石灯笼内部发出温暖会呼吸的暖黄色蜡烛柔光。
2. 雨雾与丁达尔效应：空气中有缓缓弥漫的晨雾粒子，斜阳透过枫树枝叶在雾气中形成清澈的日照光束（God Rays）。

交互系统与沉浸模式：
1. 沉浸隐藏：按下键盘 H 键可无缝触发/退出“纯净沉浸模式”，自动平滑淡出隐藏所有 UI 控制面板、文本提示与按键引导，只留纯净的 3D 渲染画面；按下 F 键切换全屏。
2. 视角控制：鼠标左键拖拽平滑环视庭院，滚轮缩放观察蜗牛与苔藓微观细节；闲置时相机自动缓速巡航。
3. 水洼互动：鼠标双击水洼表面，触发一朵激起的水花与扩散涟漪，附近的微型水滴粒子随之散开。
4. 界面控制：右下角极简透明 UI 控制面板：调节降雨强度（晴朗无雨/细雨绵绵/暴雨）、调节时段色温（清晨冷光/正午日光/夕阳金黄/夜间月光）；按下空格键触发“风吹叶落”，大量红枫叶片随风飘落。

技术要求：
1. 批渲染优化：成千上万片枫叶、地表卵石与苔藓绒毛大量使用 InstancedMesh 批渲染以保障帧率；
2. 高级材质：使用 MeshPhysicalMaterial 配合 Canvas 过程生成贴图呈现苔藓粗糙度、湿润石材与竹子清漆层；
3. Shader 核心：自定义 Shader 实现惊鹿倾倒水流位移、水面涟漪扩散算法与雨后湿润光泽；
4. 碰撞与边界：所有落叶、蜗牛与水滴严格限制在庭院固体与地面边界网格以内，杜绝穿模。
5. 视觉质感：宁静深远，光影柔和细腻，呈现极高质感的日式雨后禅意美学。

提示词3：
用 WebGL (Three.js r160 CDN) 创作一个高精细度、写实风格的沉浸式热带雨林水草生态鱼缸场景，输出为可直接在 Chrome 打开的单个 HTML 文件，不引用任何外部资源，全部几何体、材质、贴图（使用 Canvas/Shader 过程生成）代码生成，目标稳定 60FPS，杜绝物体穿模。

视觉视角：全屏近距离平视与微俯瞰视角，视角聚焦于鱼缸中心。镜头支持平滑旋转与缩放，展现晶莹剔透的高透超白玻璃材质与水下光影折射。

场景主体布局：一个精致的超白玻璃长方形生态鱼缸，内部包含错落有致的沉木骨架、天然青龙石堆叠、不同高度的热带水草（如迷你矮珍珠苔藓铺底、后景蜈蚣草与红宫廷）、细砂基质层以及底部的微型水下沉木小路。

动态生物与生态系统：
1. 热带鱼群：多群不同品种的写实热带鱼（如红红绿灯鱼、孔雀鱼、神仙鱼），采用 Flocking/Boids（鸟群/鱼群行为算法）实现自然的游动、避障、聚集与散开轨迹，鱼鳍与鱼尾带有柔和的摆动骨骼/顶点动画。
2. 清道夫与虾蟹：水草与沉木表面有极小型的体态写实黑壳虾与极火虾在爬行摄食；缸底有小型鼠鱼在砂石间寻觅食物。
3. 动态植被：所有水草根据水流速度产生自然、柔和的波浪状摆动（草浪特效）。

水体与环境光影：
1. 焦散与光斑（Caustics）：水面波浪折射出动态的写实水下光斑（Caustics Shader），实时投射在沉木、石头和水草表面。
2. 焦散光束（God Rays）：顶部水族灯光穿过水面，在水体中形成明显的折射焦散光柱与丁达尔效应。
3. 动态气泡与悬浮物：底滤出水口与氧气泵持续喷出密集的微型升腾气泡粒子，水体中有微小有机悬浮微粒在光束中缓慢漂浮。

交互系统：
1. 视角控制：鼠标左键拖拽环视鱼缸，滚轮平滑缩放观察微观细节；闲置时相机自动缓速巡航。
2. 投食互动：鼠标双击鱼缸水面任意位置，在对应点生成微型鱼粮颗粒缓缓下沉，附近的鱼群会受吸引快速游向鱼粮摄食。
3. 界面控制：右下角提供极简透明玻璃风 UI 控制面板：调节水族灯光色温（正午白光/植物红蓝光谱/夜间月光蓝）、调节氧气泵气泡强度与水流速度；按下空格键触发“水下清理/换水”动态效果，水体清透度与光泽度提升。

技术要求：
1. 植被与鱼群：大量水草、石头、微型虾使用 InstancedMesh 批渲染以保持高帧率；鱼群运动采用 Procedural Animation（过程化动画）配合 Boids 算法。
2. 高级材质：超白玻璃使用 MeshPhysicalMaterial 展示高透光率、薄物理厚度与折射率（IOR 1.52）；水面使用动态法线贴图模拟真实水波。
3. Shader 核心：自定义 Shader 实现水下丁达尔光束、水底动态焦散投射、水草波浪形顶点位移。
4. 碰撞与边界：建立严格的水体与固体（沉木、石头、玻璃缸壁）边界约束，所有鱼类和虾类严格在水体及安全物理碰撞范围内活动，杜绝任何穿模现象。
5. 质感与氛围：光影柔和自然，水体清澈灵动，呈现出高质感写实生态水族箱的宁静与生机。

提示词4：
用 WebGL (Three.js r160 CDN) 创作一个体素微缩建筑工地沙盘场景，输出为可直接在 Chrome 打开的单个 HTML 文件，不引用任何外部资源，全部几何体、材质、贴图使用代码生成，目标稳定 60FPS，杜绝物体穿模。 场景载体：整套工地微缩模型摆放在室内深色实木工作桌面上，桌面边角散落蓝图图纸、钢卷尺、安全帽摆件、金属水平仪，第三人平视人眼高度视角观察整个沙盘。 工地主体布局：完整施工工地，划分基坑开挖区、钢筋加工棚、物料堆放区、在建高层楼房基座、临时板房办公区、渣土堆放区、临时施工道路。 动态机械设备：多台体素挖掘机持续作业，铲斗往复挖掘基坑土方；轮式渣土卡车循环行驶，开到挖掘机旁接土，满载后驶往渣土堆卸料；多台塔式塔吊回转吊起重钢筋、混凝土料斗，来回吊运物料；混凝土搅拌罐车缓慢行驶，小型装载机平整地面。 人物与细节：大量体素工人各司其职，有的绑扎钢筋、有的搬运建材、有的指挥塔吊、有的操作小型工具、安保人员在出入口巡逻；工地设置围挡、警示彩旗、施工指示灯、临时照明灯、脚手架、堆叠钢筋、水泥堆、砂石料堆、施工围挡大门、临时水电杆、安全警示标识。 环境与昼夜系统：完整日夜循环，黎明、正午、黄昏、夜晚四套天色；夜晚工地探照灯、塔吊灯、板房窗户向外发出暖辉光；尘土粒子效果缓缓飘散。 交互系统：鼠标拖拽环视相机，闲置时自动缓慢环绕场景；鼠标滚轮缩放视角；鼠标点击桌面前方实体模拟控制旋钮开关：调节工地设备运行速度、开关昼夜循环、切换施工尘土强度；按下空格键触发模拟暴雨天气，雨滴粒子、地面湿滑反光，工地灯光亮度提升。 技术要求：大量物体使用 InstancedMesh 实例化批渲染提升性能；自定义 shader 实现尘土粒子、灯光光晕；所有运动物体做好碰撞约束，不发生穿插穿模；全部工地元素限定在沙盘桌面范围之内，不会超出场景边界。色彩丰富，体素方块颗粒质感明显，细节饱满。
